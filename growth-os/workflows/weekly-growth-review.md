# Weekly growth review (OGILVY, Mondays)

| Part | This loop |
|---|---|
| Check cadence | Mondays (proposed 12:00 UTC) |
| Acts when | Always: the report is written even when nothing moved |
| Purpose | One view of whether marketing is producing customers, and next week's three jobs |
| Skills used | `product-marketing`, `marketing-ideas`, `launch` |
| Loop body | 1. Read each KPI in `metrics/kpi-definitions.md` from its source, with the time. 2. List `growth` issues closed last week with their outcomes. 3. Compare to last week's report. 4. Pick three jobs for next week, each tied to one KPI and one active agent. 5. File the report as one issue titled "Growth review <date>" |
| Self-check | Every number has a source and time or says "not measured". No KPI is estimated. Jobs respect the autonomy table |
| State | Last week's report issue (the comparison point); the title date is the dedupe key |
| Stop / bail-out | If a report for this date exists, comment on it instead. If a KPI source fails, mark it "not measured" and continue |

The report fits on a phone: KPIs as a short table, then what shipped, what was learned, next
week's three jobs, and anything waiting on James (one line each).
