## Execution boundary

Run the actual exported component and PDF renderer from immutable subject source in credentialless, read-only, network-isolated Node22 containers. Install no candidate dependencies and execute no candidate configuration, lifecycle scripts, assertions or test runner. Trusted finite action, navigation, basket and display seams retain private controller state. Parent-owned expected values and assertions are never mounted into the subject container.

Use a separate dependency installation prepared from the trusted package manifest, lock and retained vendor archive, with lifecycle scripts disabled. Keep host tests on their existing toolchain: their generated caches must not enter the candidate mount. Retain the preparation receipt and installed-byte inventory, validate the chosen runtime's inputs and cache absence, and compare its bytes after collection. Package versions or a matching lock alone do not authenticate installed bytes or establish independent dependency review.

Validate Git modes and canonical paths before materialization, reject path/case collisions and excluded control inputs, and record the actual source bytes. Git archive identity alone does not prove literal Git bytes because attributes can transform exports. Bind the parent toolchain, dependencies, fixture, collector, parser and complete execution closure independently from subject source identity.

Check directory prefixes as well as full filenames for case aliases. Exclude fixture, test, private and holdout path families from metadata before reading any blobs; retain only aggregate exclusion counts and sizes. Output attempts require fresh canonical paths under the owned ignored directory, with every existing ancestor checked for symlinks. Cleanup needs an explicitly observed successful empty native container inventory; missing output cannot establish absence.

Collect bounded actual PDF bytes. A separate credentialless parser container derives text and geometry; the credentialed parent does not parse arbitrary PDFs and does not accept child-supplied geometry or pass counts. Keep original renderer font sizes and all provenance. Public finite cases do not certify arbitrary inputs or prevent a subject from overfitting known examples.

Start with the existing reviewed limits: 45 seconds, 768 MiB, 128 PIDs, one CPU, 32 MiB temporary storage and 2 MiB output. Dependency loading is measured separately from full case capacity. Resource/setup failures remain blocking; any limit change needs evidence and review. Every stage must verify its owned container is absent after cleanup.
