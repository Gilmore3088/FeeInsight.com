# Prospective corrective-source evidence

The old generic regression builder clipped stored source text and could count unavailable source
input as a replay. Controlled old-source witnesses are retained under Reports/evidence/deming-source-evidence-2064;
the production extent of clipping or label errors is unknown. Existing generic source history is
preserved, not re-labelled by a checker that cannot establish its expected label's truth.

This bounded #2064 implementation uses the existing authorized admin correction as a separate,
prospective human-validated-edition context. Its canonical receipt captures the exact checked
normalization, actual action/feedback origins and immutable correction fields in the original
transaction. Initial enrollment validates the live origins; replay retains those fingerprints in
the canonical correction after routine event trimming or nullable operational FKs. Original
extraction binding remains unknown. A validated later edition is not an original Knox miss.

The real one-document metadata selector filters unavailable/invalid evidence before its existing
LIMIT, then admits a whole-case byte-bounded prefix. Native controls cover invalid-prefix admission,
Unicode/encoding, actual schema/codec, maximum supported bodies, savepoint failure and healthy retry,
concurrent insertion, post-lock canonical drift, retention, paired semantics and actual bounded
fixture events. The first WIP 300-context query exceeded the unchanged two-second statement limit;
metadata-only projection removed repeated full-body CTE copies. That failure is preserved as evidence.
No limit/index/schema or timeout was raised to pass it.

The human correction remains the label owner. Passing the pair only shows that the deployed rule
refuses the old value and accepts the corrected value in that frozen context; it does not prove the
human label independently, current official authority, missing-fee recall or complete product/rate/
condition applicability. Unknown and unsupported dimensions are not made into negative fee lessons.
The canonical receipt is application-owned immutable history, not a cryptographic defense against
a privileged database writer.

The actual run may save fixture chunks and a manifest. **There is no production-artifact-to-CI import
handoff.** General multi-document/original-extraction capture, historical source-case policy, other
error families and full #2064 automation remain open. #2056 remains closed. No extra James checking,
production repair/replay, provider/source request, scheduler or control activation is part of this change.

A separate controlled native before-fix witness showed the new learning observer could pair an
AST's stored source-hash A with document-hash B while owner, normalized body and text hash were
valid. The bounded protocol now preserves and checks that selected-edition association; null,
missing, mismatched and pre-seal changed evidence is unavailable without changing the authorized
fee correction. Hash equality describes internal association, not independent original-byte proof.
