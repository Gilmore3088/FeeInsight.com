# Define the weekly live sampling and repair protocol

[#1923](https://github.com/Gilmore3088/FeeInsight.com/issues/1923) asked for a written sampling, error, confidence, correction and retest plan after live and stored-copy audit results diverged. The existing local workflow already prepares 50 whole institutions in five packets with bank/CU, asset-tier and Census-region strata; it does not supply a justified population confidence interval, and its historical W43 draw provenance is incomplete.

The [weekly live fee accuracy plan](../../plans/weekly-live-fee-accuracy-plan.md) preserves James's sole weekly batch and existing preparation method. It defines full fee identity, current-source applicability, rates, conditions, effective dates, missing-category/fee denominators, immutable evidence and process-first paired retests. A conservative stratified hypergeometric bound treats each institution as a cluster, budgets unresolved outcomes and largest unseen clusters, and leaves zero-sampled/excluded populations unverified. Reproducible synthetic examples include perfect samples, unequal clusters, multiple strata, unresolved sources and zero allocation. An all-correct sample cannot manufacture a 100%–100% fee interval.

Historical 62–63%, 65.2%, later W43 68.48% and automated 99.5% figures retain their distinct dates, cohorts, definitions and provenance. Stored-source/shared-validator limitations and a documented scoring change explain comparability problems; their numerical contributions to the gap are unquantified. The original rows are not overwritten or re-adjudicated. A missing-category count is not a recall denominator.

Verification checks the exact rational confidence examples, tail inversion/coverage on small synthetic finite populations, Markdown links and repository documentation guards. No bank fetch, new draw, human confirmation, runtime change, provider call or production write is part of this change. The primary workspace's untracked weekly workflow and evidence files remain untouched.

This closes the written plan in #1923 only.
